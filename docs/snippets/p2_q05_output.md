# p2_q05 - Campaign effort

**Question:** How does the number of contacts within the current campaign relate to conversion, and how much outbound effort is consumed by repeated contacting?

**Method:** response rate by attempts bucket; effort share from campaign counts.

| Attempts | Contacts | Subscribers | Response % |
| --- | --- | --- | --- |
| 1 | 17,642 | 2,300 | 13.04 |
| 2 | 10,570 | 1,211 | 11.46 |
| 3 | 5,341 | 574 | 10.75 |
| 4-5 | 4,250 | 369 | 8.68 |
| 6+ | 3,385 | 186 | 5.49 |

83.32% of all outbound contacts go to clients needing more than one attempt.
It takes on average **22.8 contacts per subscriber**.
